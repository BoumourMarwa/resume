Application De Gestion De Location De Voitures

Java EE Spring Boot MySQL Thymeleaf Docker

Développement d'une plateforme complète permettant la gestion avancée des utilisateurs (admin/client), des voitures, des réservations et des paiements virtuels. L'application intègre également la génération de factures PDF et des tableaux de bord analytiques.
